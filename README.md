# homebrew-anote

Homebrew tap for [aNote](https://github.com/mph-llm-experiments/anote-editor),
a personal Tauri-based notes editor.

## Install

    brew tap mph-llm-experiments/anote
    brew install --cask anote

aNote is unsigned. The cask strips the quarantine attribute on install
so the app launches without the right-click → Open dance.
